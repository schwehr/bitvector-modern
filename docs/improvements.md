# Future Improvements

Possible future enhancements for the BitVector project:

*   **Performance:** Investigate using a C or Rust extension module for critical hot-paths in the core implementation.
*   **Typing:** Re-enable strict static type checking checks (e.g. strict mypy) in CI when development slows down.
*   **Benchmarking:** Expand the benchmarking suite to cover more operations and larger bit vectors.
